# 架构与实际限制

## 0.12.0原流程适配

规范检索实现在原项目retrieval_pipeline.py；终端03_extract_relations.py与网页工作进程调用同版函数。scripts/sync_original_core.py同步14份核心模块并生成内容校验清单，测试核对原源文件与发布副本。配置、进程隔离和页面是适配层，不再独立实现另一套融合排序。

原JSON索引保留原分片编号和BM25加分，PubMed摘要参与同一关键词融合分支。向量仍只在有限候选内编码和搜索。查询缓存校验候选原文及模型版本，跨查询向量以原文与模型标识复用；新缓存独立保存，不覆盖缺少版本信息的历史缓存。重排序模型在同一工作进程内复用。

网页精排先于付费LLM，保留原文快照、实际方法、排序分数和预算。访问归属、目标、别名和片段数量与原精排记录绑定；部分失败不能当作完整精排提交。抽取继续经过原句检查、范围检查和人工复核，原终端宽泛关系任务保持其原任务定义。

下述SQLite入口是独立的关键词与逐篇覆盖路径；原流程入口不通过SQLite重新分片或替换原BM25评分。


## 关键词入口的处理范围与预览

第二步默认批量模式，显示当前候选总数；批量提交直接使用当前`papers`清单，不读取预览选择。单篇预览和获取正文放在可选折叠区。
五篇多选框仅在手动模式渲染，手动提交仅使用所选编号。切换处理方式重置对应外发确认；材料、范围和预算变化继续遵循原有确认规则。

## 科研界面

`src/ui_theme.py`集中管理白色工作区与浅灰分区、来源状态、研究流程示意、场景卡片和证据标签；原生表格、输入和下载使用一致的浅色主题。来源数字来自当前索引元数据，模型仅显示配置状态，不冒充连通性检查。流程图是工作流示意，不是生物学关系网络；教学条数明确标为预设。
用户或来源文字进入自定义HTML（网页标记语言）前进行转义，字体和矢量图形均不请求外部资源。业务规则、调用权限、预算、历史及人工答案保持原样。

## 展示与结果阅读

默认页签为人工示例；三个固定教学场景经正常任务、检索、引用匹配、历史与导出流程，使用预设标注，不创建模型客户端。后台校验场景名称、固定目标、来源和任务范围，不能把场景标志用于真实抽取。旧教学材料与历史继续兼容。
`src/result_overview.py`（结果概况模块）先统计候选、已核对与比较待核对记录。条件表只使用人工接受或修正的合范围证据；物种、人群、组织、测量或比较双方缺失时单列；保留相反方向和统计说明，不按论文数量投票。相同字段不证明研究可比或独立。
`src/showcase.py`（教学与历史复盘页面）区分人工案例与已保存旧任务记录。最小复盘不包含原文或人工姓名；新报告不计算医学准确率。[工程与历史效果报告](PORTFOLIO_REPORT.md)记录检查范围。

## 关键词入口的网页任务流程

当前候选队列支持自动分批扫描：最多300篇，每轮最多50篇及120个请求名额，逐篇、逐片段执行。
每篇独立选取1–6组，预算耗尽或人工暂停后保持同一任务与复核记录；恢复时跳过成功组，中断与失败不自动重发。
私有`scans/`保存原子写入的计划、片段、尝试与模型缓存；每次调用前先写入进行中状态，未知结果需要明确重试。
检查点独立于临时任务目录，删除历史时一起删除。原模型设置或提示变化会阻止混用旧扫描。见[批量扫描指南](BATCH_SCAN_GUIDE.md)。

当前使用`disease_vs_normal_v1`（疾病与正常对照）任务，网页新提交均使用该范围；旧脚本及历史默认`legacy`（旧任务）。
独立提示、缓存版本和历史标记避免把旧输出直接当作新版结果。旧四字段/七字段评分仍只用于原任务。
本地命中片段补入同篇前后各最多两个相邻片段、相差不超过一个PDF页，正文合计不超过9000字符；保留独立片段边界。
模型请求明确传入片段边界，引用不允许跨边界拼接；表达与比较原句分别绑定实际来源位置。
比较检查是保守文字规则，分为符合范围候选、待核对和范围外；人工修正后重新检查，但不代表医学认证。
Europe PMC可独立补充发现论文，按一致编号合并来源，公开检索不创建模型客户端。

真实文献页按本地/混合/在线检索、候选与处理方式、模型抽取三步展示。按论文索引返回候选，再从处理范围内论文的完整已索引文本中重新检索有限片段；人工示例与已有材料单独放在页签。
页面显示本地覆盖、在线文献开关、模型配置是否非空、真实模式及会话权限；配置状态不是接口连通性测试。
抽取目标来自已提交检索，选择文献变化后重置外发确认。实际提交仍执行后台原有的输入、归属、配置、权限和外发校验。
模型配置仍为部署端私有配置，不接受公共网页访客临时输入个人密钥。见[配置说明](MODEL_SETUP.md)。

独立检索与收藏流程：PubMed 限量检索 → 与本地资料按标识去重 → 私有收藏 → 可选开放全文。
文献操作不创建模型客户端。只有显式提交抽取任务、开启模型并通过授权与外发确认后才调用模型。
检索默认不强制表达词汇，按固定论文编号集合分批取回；有篇数上限时保存覆盖提示，不冒充完整召回。
Europe PMC 全文经元数据与正文标识核对后按章节段落解析，参考文献、图片和结构化表格不作为已解析正文。
摘要与正文保留来源范围，抽取只检索有限片段。详见[文献检索指南](LITERATURE_GUIDE.md)。

```text
网页会话 → 输入与预算校验 → 有界后台队列 → 独立随机任务目录
                                       ↓
示例 / 上传论文 / PubMed / 只读公共库 → 关键词检索 → 模型抽取（真实模式）
                                       ↓
                 原句匹配、来源绑定、复核标记、去重 → 本任务下载
```

网页会话使用随机恢复码，数据库只保存其 SHA256（内容摘要），不保存恢复码原文。
查询、下载、复核、修改记录和删除均校验归属；随机任务编号本身不授予访问权。
线程池不修改全局标准输出，不从任务后台调用网页框架。
任务编号、上传文件名随机生成；原始文件名只用于展示，不能决定保存路径。

## 检索与原项目的区别

原项目的完整语料和配置保持在原位置。私有配置只读引用原模型配置；网页指向完整可读PDF文本的新索引，旧30篇试点库与人工评测数据保留。
论文、模型、缓存、摘要样本、私有配置和密钥均不进入发布包。
网页采用 SQLite FTS5，先找基因与疾病共同出现的文本，再补充只含基因的文本；别名匹配保留词边界检查。
这是一种可部署的关键词检索基线，不宣称具有独立全库语义召回能力。
全文导入脚本按行读取逐页文本，文档和片段两级索引使用单进程及有限数据库缓存；兼容迁移脚本仍可读取旧 `chunks.jsonl`；统计和排名方式与旧自实现不同，不能把两者的分数直接比较。

原向量模块保留为研究扩展：缓存以候选内容、模型名称和修订版本为依据；本地模型还记录配置和权重文件的大小、修改时间。
更新远程模型应修改 `EMBEDDING_MODEL_REVISION`，正式实验建议使用不可变提交编号而非 `main`。
关键词入口不加载这些模型；原流程入口通过配置的模型环境执行。模块数值测试不等同于生物医学质量验证。

完整覆盖、自有PDF导入及去重边界见[全文库指南](FULL_LIBRARY.md)。空文本不进入索引，不把文件数量当作独立论文数量；没有已核验编号时不按标题或文件名合并在线记录。

## 证据检查

引用经过空白规范化后必须是输入上下文中的连续原文片段，否则剔除。
来源编号、标题、页码不由模型决定。新输出强制待复核；模型自报置信度不被当成已校准的正确概率。
出现否定词只增加复核标记，不覆盖所有关系；这避免错误抹掉另一种终点的发现，但不能代替语言理解。
重叠片段按来源、目标、原句和所述疾病关系去重，不擅自把不同论文的结论合并成医学结论。

## 持久历史与复核

`history.sqlite` 保存查询、状态、机器结果、引用上下文和来源版本；复核记录采用逐次追加方式。
机器结果不直接改写，页面与导出按最新复核生成当前视图。JSON、CSV 和电子表格均保留机器原值。
恢复码只作为访问凭据，不是完整用户账号，也不证明复核人填写的身份真实。
数据库使用回滚日志与单进程文件锁，不启用多进程共享；不要把运行目录放在不支持文件锁的存储上。
服务启动时把排队和运行任务标为“已中断”，不自动重新执行模型请求。
历史持续保存，最近 200 条在页面列出；临时文件单独清理。数据库长期增长，需要人工管理和停机备份。
程序记录提示与语料内容摘要、候选摘要、模型别名及接口返回的模型名称；这些信息帮助追查，不保证提供商模型永不更新。

## 试点评测

以论文为单位固定开发/测试分组，词汇抽样提示不作为人工答案。
抽取评测按表达方向、疾病关系、关系类型、物种的组合严格匹配，引用另行检查。
0.5.0增加可选 `scope_measurement`（范围与测量）七字段模式，将关系范围、研究对象、测量类型一并比较；`legacy`（旧版）四字段模式继续兼容。
七字段模式要求人工参考明确填写这些字段；缺失不自动补成“不明确”。评分检查主引用是否存在，不认证关系支持句的完整语义。
无人工确认、缺预测、失败、原文版本不同或输入截断时暂停指标；检索记录不能当作抽取结果。
检索召回率仅限已标注试点论文，不代表完整语料库。见[阶段评估报告](PORTFOLIO_REPORT.md)。

## 预算和故障

新版手动模式每篇最多12组、所选篇数乘以额度最多24组；扫描每篇每轮最多6组，每轮最多120个请求名额。
每组正文最多9000字符；旧任务单条最多12000字符。输入另含任务说明和来源信息。
手动模式两线程，默认不重试，可明确选择失败后重试一次；扫描逐组执行、不自动重试，每次最多2048输出词元。
记录失败请求和剔除引用数，处理状态独立于证据数量；真实模式绝不以规则结果冒充模型成功。
PubMed 请求使用限频、超时和重试，缓存按实际检索式与数量区分；部分抓取不会缓存成完整成功。

这些限制是费用和资源边界，不是费用金额承诺；实际费用由服务商、模型和输入长度决定。

## 尚未实现或验证

- 全库独立语义向量召回、结构化表格解析、扫描论文文字识别。
- 专家确认的医学参考答案、已验证的医学质量指标，以及真实全库负载测试。
- 完整用户账号、跨进程任务队列、中断任务自动续跑、多副本运行。
- Docker（容器工具）镜像运行和正式公网环境。

已完成按次授权的小批公开摘要真实调用并记录用量；这只验证有限样本的连通与抽取，不替代独立医学质量评估。

本版本为小规模科研自用与进一步验证准备，不应描述成已经通过大规模生产验收。
