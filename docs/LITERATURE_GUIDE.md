# 独立文献检索与开放全文

本指南描述独立关键词与逐篇扫描入口；原项目混合精排见[原流程配置](MODEL_SETUP.md#复用原项目检索流程)。

文献发现支持仅本地、本地＋PubMed（生物医学文献平台）或仅PubMed，以及可选Europe PMC（欧洲生物医学文献平台）独立检索。完整本地接入见[全文库指南](FULL_LIBRARY.md)，批量处理见[扫描指南](BATCH_SCAN_GUIDE.md)。本次发布整理未新增真实文献或付费模型请求。

本版将“发现论文”“取得文本”“模型抽取”分开。模型关闭时，仍可在线检索、保存摘要、获取开放全文和下载资料。
API（程序调用接口）分为文献接口和模型接口；文献操作不会自动调用模型。

## 已有集群环境如何使用

代码更新后，请在原来运行应用的终端按 Ctrl+C 停止自己启动的应用，再运行：

```bash
source .venv-release/bin/activate
RAG_ENABLE_LIVE=false RAG_ENABLE_LITERATURE=true bash scripts/run_local.sh
```

在项目已有环境、项目目录执行。上述命令开启在线文献、关闭模型；真实抽取需按[模型配置说明](MODEL_SETUP.md)另行启用。不要启动两个共用同一运行目录的进程。
浏览器刷新原访问地址，切换到“真实文献与模型抽取”页签，在第一步输入基因与疾病。远程连接方式沿用[部署说明](DEPLOYMENT.md)。
本轮没有替用户停止或启动网页进程，也没有修改集群系统服务。
升级或回退代码前，先停止自己的服务并备份私有运行目录；旧代码不能保证理解新版任务字段。

## 1. 本地检索与在线补充

输入单个基因、疾病英文名称及必要别名，点击“检索候选文献（不调用模型）”。
例如 rheumatoid arthritis 是类风湿关节炎，type 2 diabetes 是 2 型糖尿病。

- 默认搜索基因与疾病在标题/摘要中的共同出现，不额外强制表达或风险词汇。
- 勾选聚焦选项后增加表达/疾病关系词汇条件，可能漏文献；实际检索式保存在运行记录中。
- 每次最多取得 1–100 篇，默认 40 篇；先固定搜索返回的论文编号，再按每批 20 篇获取记录，避免分页时排名变化。
- 可先查完整本地库并选择是否补充在线来源。仅本地不需要联网；混合模式按每个来源的篇数上限取候选，按已知且一致的PMID（文献编号）、PMCID（全文库编号）或DOI（数字文献标识）合并。没有可信编号的本地文件保留独立记录。
- 本机已接入17,297份可读PDF页文本，3份空文本列入缺口；源码下载者需配置自己的库。基因别名和疾病缩写仍需人工检查歧义。
- 页面展示匹配总数、本次取得数量和是否达到上限；“完成”只表示本次限定范围处理完成，不代表取回所有相关论文。
- 没有摘要的文献仍保存标题和编号。部分抓取失败会明确说明，不缓存为完整成功。

查询缓存为 24 小时，可勾选重新访问接口。检索会向 PubMed 发送查询词，不发送本地论文正文，也不连接模型。
PubMed 是生物医学文献平台；接口行为参考 [NCBI 官方说明](https://www.ncbi.nlm.nih.gov/books/NBK25501/)。

## 2. 收藏、恢复和下载

检索结果自动进入当前研究空间的私有收藏，保存在 `.runtime/literature.sqlite`（轻量数据库）中。
侧栏恢复码用于找回这个空间的历史和收藏，数据库只存恢复码摘要。任何持有恢复码的人都能访问该空间，请保密。
页面显示最近200篇，每个空间最多保存1000篇。批量模式无需勾选，可在折叠区逐篇预览摘要或获取开放全文；只有手动抽取模式才显示最多五篇的选择框。资料下载范围以页面下载按钮旁的说明为准。
在“文献收藏管理”可以删除所选收藏。删除任务历史与删除收藏是两个操作，互不自动连带。
已经写入历史的证据与文献任务快照仍保留，按各自入口删除。

下载的 JSON（结构化数据）保留论文编号、摘要、内容摘要、来源记录，以及已取得的正文段落与许可声明。
真实文献、收藏、缓存、恢复码和运行结果不放进公开源码包。公开代码不等于公开论文数据。
服务停机后备份整个私有运行目录与配置；收藏不会按 24 小时任务临时文件规则自动删除。
查询缓存和全文缓存目前按读取时检查 24 小时有效性，缓存文件不自动定期删除，可在停机时自行清理缓存目录。

## 3. 获取开放全文

### 可选的第二个发现来源

检索选项提供Europe PMC独立搜索，默认关闭，按每次每源最多100篇、固定公共接口、25秒超时和24小时缓存限制。
只查当前基因、疾病和别名的标题/摘要；与PubMed和本地记录仅按一致标识合并，来源记录保留。
来源失败显示部分完成，不会伪装成无文献。可包含预印本，页面提示版本，提取后需单独核对。
检索结果条数表示本批返回齐全，不表示检索到全部相关研究；它不替代通用网页搜索。
官方接口说明见[Europe PMC REST服务（程序调用服务）](https://europepmc.org/RestfulWebService)。

### 按编号获取可用正文

在单篇预览中选择文献，点击“获取所选开放全文（不调用模型）”。程序按论文编号查询 Europe PMC（欧洲生物医学文献平台），
只有接口标记为开放且有可核对的全文编号时，才请求全文 XML（带结构标签的文本）。
参考 [Europe PMC 官方接口](https://europepmc.org/RestfulWebService)。

正文下载后再次核对论文编号和已知的数字文献标识，身份不一致则拒绝绑定。
保存原始响应内容摘要、来源地址、许可声明、章节、段落位置和获取时间；同名标题本身不作为身份依据。
只解析正文段落，图片、结构化表格、参考文献列表和补充材料不作为已解析证据。单次响应上限 5 MB，正文上限 100 万字符和 1000 片段。
长段落分成有重叠的片段，保持原章节与段落编号。超限或无法解析时明确报错，不把截断正文说成完整处理。

全文状态分为：未请求、已取得正文、暂无可取得开放全文、请求失败。
“暂无可取得”可能与许可或接口覆盖有关，不表示论文没有全文；请求失败也不表示没有研究证据。
更新失败时保留先前已核验的正文，并提示最近一次尝试失败。
本版只使用固定公共接口，不自动访问返回的任意出版社链接、不绕过订阅权限。

## 4. 显式调用模型

“真实文献与模型抽取”页签第三步“确认目标，调用模型整理证据”是独立操作，需部署者配置并启用真实模型、侧栏通过访问口令并勾选外发确认。
当前目标来自最近已提交的检索；只编辑第一步输入框不会改变抽取目标。改变所选文献后需重新确认外发，本轮没有执行真实模型请求。

可选择检索摘要与已取得正文，或只使用摘要。没有正文时使用已有摘要或本地片段；资料不足不自动补造结论。
只把有限候选送给模型，每条结果保留摘要/正文标识、来源位置与内容摘要，再经过逐字引用核对。
候选数量仍受原抽取预算限制，不会因为下载了全文就把整篇论文全部发送给模型。

摘要没有写某种关系，应记为信息不足，不能推出“没有关系”。正文也可能转述其他研究，需核对实验对象、物种和具体条件。
标题、摘要、模型分数、检索排名都不能单独证明因果关系或医学正确性。

## 5. 验证和边界

自动测试用模拟响应检查分页、去重、原文身份、错误处理、恢复与访问隔离，并禁止未模拟的外部请求。
有限公共接口检查脚本默认只显示计划：

```bash
python scripts/check_literature.py --output .runtime/literature-check-new
```

加入 `--execute`（实际执行）后，固定查询最多取 3 篇公开记录；最多检查 3 个全文状态、下载 1 篇正文，不调用模型。
输出目录必须为新目录，可用 `--search-report` 复用最多三篇的已有查询记录。
检测报告区分摘要接口与全文接口是否实际验证成功，不会把“未开放全文”算作成功获取正文。
独立模型验证脚本 `validate_model.py` 的行为保持不变，仍需两个执行开关才会调用模型。

本地检索与在线检索的相关性仍需人工评测；100 篇上限、标题/摘要检索范围和别名不全都可能造成遗漏。
本版不支持任意网页搜索、谷歌学术抓取或完整系统综述；没有因为接入更多来源而声称医学准确率提升。
接口网络访问仍受集群出口、服务商限流和服务可用性影响。本进程限频不能保证集群共享出口的总请求频率。
