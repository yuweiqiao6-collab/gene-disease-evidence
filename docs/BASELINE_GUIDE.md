# 疾病与正常对照的上下调证据

0.10.0的入口是一个基因和一种疾病。方向始终表示疾病组相对正常对照的表达量变化。
例如原文写“正常组更高”，结果应记为疾病组降低；“用药后降低”没有独立疾病与正常对照结果时，不进入本版主结果。
人体、动物、细胞，转录本、总蛋白、循环蛋白浓度、膜表面丰度，以及不同组织分别记录。
未见显著差异保留统计限定，不等于证明两组相同，也不能推出治疗应抑制还是激活该基因。

## 网页怎么操作

1. 在第一步输入基因和疾病英文名称，并按需提供别名。选择本地、联合或PubMed（生物医学文献平台）检索。
2. 如需增加来源，在检索选项勾选Europe PMC（欧洲生物医学文献平台）补充检索。它默认关闭；不需要新的模型密钥。
3. 阅读候选摘要或本地片段。可预览最多5篇；批量模式使用全部当前候选，不受这5篇限制。
4. 核对目标、材料范围、每篇额度与本轮预算，完成模型权限及外发确认后调用。暂停与继续见[扫描指南](BATCH_SCAN_GUIDE.md)；检索与全文获取本身不调用模型。
5. 查看表达原句、比较原句、两组名称、研究条件和页码，再接受、拒绝或修正；下载时选择范围。

本地全文使用命中片段及同篇相邻片段补充组别定义，每组正文最多9000字符，前后各最多相邻两个片段、PDF（便携文档格式）页码距离不超过1。
摘要不与其他论文或正文强行拼接。实际输入还含任务说明及少量来源信息；字符数不是词元数。
9000字符上限比旧版单片段可能更长，实际调用前应按候选数检查用量；不把全库或整篇论文自动发给模型。

## 三个结果区域

| 区域 | 含义 |
|---|---|
| 符合范围的机器候选 | 比较类型、组别文字、目标名称与原句位置通过保守检查，仍需人工核对医学含义 |
| 比较依据待核对 | 缺少比较原句、组别不明确、目标或别名不在依据中，或来源提示综述、预印本等 |
| 不在本版范围 | 输出明确属于干预、患者亚组、其他比较、活性或定位变化，或参考文献列表 |

正常对照检查使用文字线索，会漏掉缩写或非英文名称，也可能误判“正常”“野生型”在某实验中的含义。
两段原句分别存在也不能证明它们属于同一实验，仍要核对上下文；程序没有完成语义认证。
预印本是正式发表前的论文版本；其他来源没有该标记也不意味着已确认通过同行评审。
综述与预印本候选需核对原始研究和论文版本，不作为本版默认主结果。

每段引文必须连续出现在一个保留的来源片段中，不能跨拼接边界凑出原句。表达原句与比较原句可在不同相邻片段，分别保留位置。
只点“接受”不会补齐缺失比较条件；需复制保留的原文修正比较字段，程序才重新检查。机器原值及每次修改始终保留。

主结果默认导出符合范围且未被人工拒绝的候选；可再勾选仅导出人工接受或修正的证据。
取消范围限制可导出全部输出及待核对状态用于审计。页面物种和方向筛选不改变下载范围。
主要新列包括：`comparison_type`（比较类型）、`disease_group`（疾病组）、`normal_group`（正常对照）、
`comparison_sentence`（比较原句）、`significance`（统计说明）、`baseline_status`（范围检查状态）。
`task_profile=disease_vs_normal_v1`表示本轮任务规则；旧任务记录不自动重新标注，也不复用旧任务的模型缓存。

0.10.0的“本次找到什么”只按人工接受或修正且符合范围的记录整理条件，缺失条件单列。另有“查看机器候选的条件分组”折叠区，包含未复核输出，展示出现过的方向和论文记录数。
未知条件不能当作相同条件；相反结果保留，不按多数票给基因—疾病作统一结论，也不保证跨库完全去重。

## 新目标的人工参考

旧任务的风险、机制和七字段答案不能直接作为本版完整参考。使用冻结材料生成一份空白的新任务表，原文、目标和原分组不变：

```bash
python scripts/baseline_reference.py export \
  --annotations /path/to/frozen/annotations.jsonl \
  --workbook .runtime/疾病与正常对照核对表.xlsx
```

先看“原文与来源”，再填“1逐篇判断”。只按提供的文本：摘要材料只看摘要；没有把握选“信息不足，暂不能判断”。
有比较时在“2表达证据”填写两组、方向、表达原句、比较原句和研究条件；没有比较时只在逐篇判断明确确认，不填正证据。
同一案例可复制整行追加多条证据；不同条件分开。未报告的字段须明确填写不明确，不能用空白代替。

```bash
python scripts/baseline_reference.py import \
  --annotations /path/to/frozen/annotations.jsonl \
  --workbook .runtime/疾病与正常对照核对表.xlsx \
  --output .runtime/新版人工参考.jsonl
```

导入检查原文、来源、目标、原句和字段完整性，保存到新文件，不覆盖原人工工作。空白、未完成和信息不足保持待确认。
目前只报告参考完成数量，不计算新版准确率。旧评分程序缺少本版比较组和方向基准检查，不应直接用它生成新版质量结论。
看过这些答案后若调整提示，该组就不能继续作为未参与调试的独立测试，应另留新材料。

## 能力边界

本地库＋PubMed＋Europe PMC是多来源论文检索；通用网页、谷歌学术抓取、付费墙全文、图片和结构化表格提取尚未实现。
每源候选篇数上限、别名不全和关键词排序会遗漏证据；任何空结果都不能解释为生物学上无关联。
本版新增规则和软件流程已经测试，真实模型对新目标的质量尚未做付费验证与独立人工评测。
