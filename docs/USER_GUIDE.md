# 使用说明

0.12.0首页分为“人工示例体验”“真实文献与模型抽取”“上传论文与本地库”三个页签，默认进入人工示例。
关键词入口默认使用自动分批扫描，无需逐篇勾选；逐篇额度、预算暂停和继续见[批量扫描指南](BATCH_SCAN_GUIDE.md)。
新任务固定为单基因＋单疾病，查疾病状态相对正常对照的表达变化；两组、比较原句与结果分区见[新版指南](BASELINE_GUIDE.md)。
顶部显示本地库覆盖、在线开关、模型配置和本会话权限；模型“已配置”只表示字段非空，不代表服务已实际验证。
复核时先确认疾病组与正常对照，再核对物种、组织、测量对象及支持原句，见[比较范围与人工参考](BASELINE_GUIDE.md#新目标的人工参考)。摘要不能证明的条件应保留“未知”，不要自行补全。

网页默认跳过明显的参考文献列表片段，可在检索选项关闭；这是格式线索，不会确认其他片段相关。
模型默认不重试，勾选重试会增加请求上限；改变片段数、范围或重试选项后，需要重新确认文本外发。
任务结果会列出所选论文各自进入候选范围的片段数；零片段不能当作该论文已完成抽取。
新版中文参考表见[新版核对方法](BASELINE_GUIDE.md#新目标的人工参考)；旧全文调用脚本保留旧任务，不用于自动验证本版准确率。

## 首页主流程

1. 在“真实文献与模型抽取”第一步选择仅本地、本地＋PubMed或仅PubMed，输入单个基因和疾病英文名称，点击“检索候选文献（不调用模型）”。
2. 第二步默认显示本次候选并选择自动分批扫描，当前清单全部进入候选范围。查看原文可展开“预览文献或单独获取开放全文（可选）”，每次预览一篇，不改变扫描范围。只有切换到手动抽取才显示最多五篇的选择框。切换“已保存候选”可查看最近200篇历史候选。
3. 第三步确认目标和证据范围。批量方式设定本轮篇数与请求上限，再验证口令、确认外发并开始；手动方式只处理第二步所选论文。
4. 页面下方“任务进度与证据结果”显示进度、原句、筛选、人工复核和下载。

检索和正文获取不调用模型。PubMed是生物医学文献平台，LLM是大语言模型，详细来源规则见[文献检索指南](LITERATURE_GUIDE.md)。
本地全文不需要联网，候选数量上限按每个来源计算，不是全库容量或评分。本机完整接入情况和自有PDF建库方法见[全文库指南](FULL_LIBRARY.md)。
疾病名称目前不自动翻译；例如rheumatoid arthritis表示类风湿关节炎。
抽取目标固定为最近已提交的检索目标，编辑尚未提交的输入框不会静默更换它；更换所选文献后需重新确认外发。
希望使用自己的模型密钥时，先看[个人模型配置说明](MODEL_SETUP.md)；网页访问口令不是模型密钥。

## 示例体验

“人工示例体验”页签提供“查看明确比较”“查看条件差异”“查看证据不足”三个场景。原有IL6、ABCC8、TP53案例保留在“更多教学案例”折叠区。
示例句子和标注均由人工编写，没有对应论文。它们用于体验页面和教学，不说明这些真实基因的医学结论。
示例仍经过全文检索、引用匹配、复核标记和导出流程，但不会调用模型。

## 真实抽取

部署者配置模型并启用后，在侧栏输入共享访问口令。“真实文献与模型抽取”页签先检索并确认处理范围，再调用模型；已有材料可在“上传论文与本地库”输入基因和疾病，选择来源：

- 上传自己的论文：仅支持可读取文字的 PDF，每次上传只进入本任务的专属目录。
- 管理员预建文献库：只有管理员配置了全文检索数据库时才出现，页面只读查询。

上传和实时摘要不会写入公共语料库。真实模式会向配置的模型服务发送候选文本，提交前需确认有权处理并允许发送。
新版一次查询一个基因；可填写同一基因或疾病的别名，不能把不同基因作为别名混合。
短缩写可能歧义：RA 既可能指 rheumatoid arthritis（类风湿关节炎），也可能指 retinoic acid（视黄酸）。

## 阅读证据

先看“本次找到什么”：候选与已人工核对的数量分开。条件概况仅使用人工接受或修正且符合范围的记录；条件缺失单列，不判定研究间可比性或独立性，也不生成统一医学结论。
再查看表达原句、比较依据原句、来源位置和研究物种，检查两组定义、表达方向、测量对象与研究类型。
可以展开证据查看原文上下文，按物种、表达方向和复核状态筛选。

新证据均标记“待复核”。“原句核对通过”表示该引文存在于输入文本，不能保证模型解读或因果判断正确。
“未发现所述关联”也不表示整个基因与疾病不存在任何联系。
表达差异、疾病风险、动物实验因果和人类临床证据是不同概念，不能直接互相替代。

## 保存、恢复和人工复核

在侧栏展开“研究空间与历史”，把恢复码保存在自己的私有位置。
浏览器刷新、关闭或服务重启后，可重新输入恢复码找回最近 200 条任务。没有恢复码不能从页面找回旧空间。
恢复码持有者可以读取、修改或删除该空间的结果，请不要截图公开或提交 GitHub。
真实抽取访问口令用于开启模型功能；恢复码用于访问自己的历史，两者不是同一个口令。

每条证据展开“核对或修正这条证据”，可选择“接受”“拒绝”“已修正”或“待复核”，填写复核人后保存。
拒绝和修正必须写理由；修正可修改表达方向、疾病关系、物种等字段，引用原句和来源不可改写。
“接受”表示接受机器原始判断；保留修正字段时应使用“已修正”。每次保存都会追加修改记录，机器原值始终保留。
两处页面同时修改同一条证据时，较旧页面会被要求刷新，避免覆盖他人修改。

历史保存在私有运行目录的 `history.sqlite`（轻量数据库文件）中。结果会保留已引用的上下文，直到手动删除历史。
上传全文、临时索引和候选快照最长保留 24 小时，繁忙时可能提前清理；历史记录不会因此一起删除。
批量扫描的候选文字、模型缓存与检查点持续保存，直到删除对应任务，不受临时文件清理影响。
“复核修改记录与历史管理”可下载修改记录，或在勾选确认后删除整个任务。重要原文请另行保存。

## 处理状态

| 页面状态 | 含义 |
|---|---|
| 正在排队 / 运行中 | 后台尚未结束，页面每 2 秒更新 |
| 处理完成 | 流程完成，结果仍需人工复核 |
| 无候选片段 | 本次范围内没有匹配文本，不代表医学上没有关系 |
| 未提取到证据 | 找到了候选，但模型没有返回符合任务的证据 |
| 部分完成 | 返回了部分证据，但有请求失败或无法匹配原文的引用 |
| 处理失败 | 请求失败、文件无效、配置问题或结果无法通过检查；不应解读为无证据 |
| 已中断 | 服务重启时尚未完成；普通任务手动重提，扫描可确认后继续，均不自动重发 |
| 已暂停，可继续 | 扫描达到本轮预算或主动暂停；确认新一轮上限后继续，不重发成功组 |

扫描论文没有文字时会明确提示需要识别文字，不会冒充“没有关系”。
PubMed 可能有无摘要的文献；无可读摘要与服务不可访问会分别说明。

## 下载列名

新版默认下载符合疾病—正常对照范围且未被人工拒绝的行；取消范围限制可下载全部输出。旧任务默认下载全部行。
勾选“仅导出人工接受或修正的证据”可进一步排除未复核记录。
物种和表达方向筛选不会改变下载范围。电子表格默认英文列名，方便后续程序读取：

| 列名 | 中文含义 |
|---|---|
| gene_or_target / disease | 查询基因或靶点 / 疾病 |
| expression_direction / disease_effect | 表达变化方向 / 所述疾病关系 |
| relation_type / evidence_type | 关系类型 / 研究证据类型 |
| species | 研究物种 |
| evidence_sentence / source_context | 引用原句 / 输入上下文；上下文保存在 JSON 下载中 |
| paper_id / title / source_location / source_url | 来源编号 / 标题 / 页码或文献位置 / 公开来源链接 |
| file_name / page / chunk_id | 原文件名 / 页码 / 被引用片段标识 |
| quote_verified / needs_review | 引用匹配通过 / 需要人工复核 |
| statistical_evidence | 模型抽取的统计数据，仍需人工核查 |
| comparison_type / disease_group / normal_group | 比较类型 / 疾病组 / 正常对照 |
| comparison_sentence / comparison_source_location | 比较依据原句 / 对应来源位置 |
| significance / baseline_status | 统计显著性说明 / 本版范围检查状态 |
| synthetic | 是否人工编写的示例 |
| notes | 模型备注或复核原因 |
| evidence_id | 单条证据的稳定编号 |
| review_status / review_revision | 人工复核状态 / 修改版本序号 |
| reviewer / review_reason / reviewed_at | 复核人 / 复核理由 / 保存时间 |
| machine_result | 机器原始结果；文本表格和电子表格内以结构化文本保存 |
| content_level / source_type | 证据范围 / 来源类型；abstract 表示摘要，fulltext 表示正文，snippet 表示已有来源片段 |

任务按研究空间恢复码隔离，只显示和下载该空间的任务，不提供服务器文件浏览功能。

## 混合检索与精排入口

先按[模型与原流程配置](MODEL_SETUP.md#复用原项目检索流程)接入原索引和模型。该入口先对整次查询精排，再把最多5／10／12／15组片段交给LLM，预算与逐篇扫描不同。检索与精排不调用LLM；需要单独通过口令和外发确认。
结果显示本地与在线候选数量、向量复用和新计算数量、实际方法及各阶段分数，可下载精排后的原文和来源记录。前几条未覆盖某篇论文，不代表该论文没有证据。需要让更多候选文献获得检查机会时，可选择“逐篇证据扫描”；它按每篇预算处理当前候选清单，也不能保证覆盖全部证据。
