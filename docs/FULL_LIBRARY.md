# 本地全文库：从文件到证据结果

本指南建立SQLite（轻量数据库）关键词索引，适用于独立关键词入口。原项目混合精排直接复用原JSON索引与片段编号，见[原流程配置](MODEL_SETUP.md#复用原项目检索流程)，不要求重建已有库。

本地文献库保存可检索文本；候选清单保存某次查询命中的论文；模型仅处理你选中的论文内的有限候选片段。
这三个数量不同，不需要把全库逐篇收藏，也不会把整库发送给模型。

## 当前本机接入情况

| 内容 | 核对结果 |
|---|---:|
| 原PDF文件与对应解析记录 | 17,300份 |
| 含可读文本的文件 | 17,297份 |
| 没有可读文本的文件 | 3份 |
| 逐页文本记录 | 106,047条 |
| 检索片段 | 197,777条 |

文件数量不等于去重后的论文数量。复用旧解析文本建立了独立新库，原PDF、页文本、旧片段、30篇试点库及人工参考保留。
24份随机可读PDF的第一页与页数抽查通过；3份空文本再次直接读取仍无可读文字，需要另行OCR（从图片识别文字）。
这些是覆盖与来源检查，不是独立医学质量评测。源码包不包含本机文献或数据库。

## 在页面使用

1. 顶部查看本地可检索文件数量、空文本数量、在线开关和模型状态。
2. 切换“真实文献与模型抽取”页签，选择“本地全文库（不联网）”“本地全文库＋PubMed补充”或“仅PubMed在线检索”，输入一个基因和疾病英文名称。
3. 点击“检索候选文献（不调用模型）”。上限按每个来源分别计算，合并后可能超过单个上限；不是相关性评分或全库容量。
4. 第二步默认显示本次检索候选。列表区分来源、文内共同命中与仅基因扩展候选；可切换查看最近200篇已保存候选。
5. 默认批量扫描本次全部候选，无需逐篇选择。可展开单篇预览，按需获取开放正文；五篇选择框只在手动抽取模式出现。没有可核验编号的本地文件不按标题猜测身份。
6. 第三步确认基因、疾病、文本范围、逐篇片段数和请求预算。模型配置并启用、口令通过、勾选允许外发后，点击模型抽取按钮。
7. 下方查看证据原句、来源位置、物种、测量类型、疾病组、正常对照和表达方向，人工复核后下载表格。

本地检索不需要联网或模型密钥，PubMed（生物医学文献平台）补充只发送查询词。
LLM（大语言模型）抽取才会发送候选文本并可能产生费用。模型配置见[个人模型说明](MODEL_SETUP.md)。
本地材料没有独立摘要时应使用包含全文的范围。选定论文后重新检索其全部已索引文本，不限于界面展示的3段预览；仍由候选数控制发送范围。
更改文献选择会清除外发确认；更换本地索引后必须重新检索，不能用旧候选混入新版本文本。

## 下载者接入自己的PDF

所有命令在自己的项目目录和已准备的Python（编程语言）环境执行，使用单进程，不安装系统服务、不调用模型。
准备好可唯一识别的PDF文件名；同名文件分布在不同子目录时需先整理，避免错绑来源。
输出必须选择新路径，原文件不覆盖。

只有PDF、尚无逐页文本时，先执行：

```bash
python scripts/prepare_local_pages.py --pdf-dir /path/to/pdfs --output .runtime/my-library/pages.jsonl --report .runtime/my-library/parse-report.json
```

已有逐页JSONL（每行一条结构化记录）时可跳过上一步。每条需有paper_id（文件对应标识）、file_name（文件名）、page（从1开始的页码）、text（页文本），title（标题）可选。
再建立索引：

```bash
python scripts/import_local_library.py --pages .runtime/my-library/pages.jsonl --pdf-dir /path/to/pdfs --output .runtime/my-library/corpus.sqlite --report .runtime/my-library/import-report.json
```

报告列出无可读文本的文件；目录中的全部PDF会登记，只有可读文本进入索引。原PDF目录应保留用于人工回查。
若解析失败或内容为空，不会被当作“没有基因—疾病关系”。脚本不识别扫描图片，也不保证表格结构或排版语义。

在私有.env（配置文件）中将以下值改为自己数据库的绝对路径；已有配置先备份，不覆盖模型密钥或口令：

```dotenv
RAG_CORPUS_DB=/path/to/app/.runtime/my-library/corpus.sqlite
```

完整重启自己的应用进程后生效。共享运行目录只允许一个应用进程；不要重复启动。
先只检索本地、不调用模型的启动方式：

```bash
RAG_ENABLE_LIVE=false RAG_ENABLE_LITERATURE=false bash scripts/run_local.sh
```

## 去重、复现与局限

在线与本地命中只根据明确且一致的PMID（文献编号）、PMCID（全文编号）或DOI（数字文献标识）合并；编号冲突会提示，不按标题合并。
旧PDF解析记录多数只有文件名、标题与页码；即使文件名形似公开编号，也不自动当作已核验身份，因此跨来源可能保留同篇候选。
数据库记录输入页文本摘要、可检索论文记录数、片段数和索引版本。摘要指文件内容的校验值，不是论文摘要。
导出保留file_name（文件名）、page（页码）、chunk_id（片段标识）和来源位置；引用逐字匹配不等于科学解释正确。

此独立入口使用关键词检索；原流程入口另有候选向量融合与重排序。基因与疾病共同出现不证明直接关系；仅基因命中的扩展候选可能研究其他疾病。
PDF页文本可能包含背景、引用其他研究、参考文献和表格碎片。人工应核对研究主体和原文，不能把检索命中率或程序测试数当作医学准确率。
本版输出逐条可复核证据，并按已记录条件整理人工核对结果，不给出跨论文的单一总判断。共享口令与恢复码适合小规模自用，公网与机构多用户运行仍需后续建设。
