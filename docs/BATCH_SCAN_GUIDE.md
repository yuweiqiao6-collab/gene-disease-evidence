# 自动分批扫描、逐篇覆盖与继续

本指南对应独立关键词入口的逐篇覆盖扫描。原流程精排按整次查询取少量片段，见[配置说明](MODEL_SETUP.md#复用原项目检索流程)；两种入口的预算含义不同。

当前默认自动分批扫描。批量模式使用当前范围的全部候选，最多300篇。
第二步显示候选数量和处理方式，无需逐篇勾选。可选预览区每次查看一篇，不改变批量范围；只有切换到手动模式才显示最多五篇的选择框。

## 第一次扫描

1. 输入单个基因与疾病，完成本地、PubMed（生物医学文献平台）及可选Europe PMC（欧洲生物医学文献平台）检索。
2. 第二步默认选择“自动分批扫描全部当前候选”；无需选文献，可按需展开单篇预览阅读摘要或本地片段。
3. 设置每篇候选组数、本轮最多处理篇数和请求名额。默认每篇2组、本轮最多20篇和40个请求名额。
4. 核对目标、材料范围与上限；通过访问口令并同意文字外发后，点击“开始自动分批扫描”。
5. 查看逐篇覆盖表、证据和原句；预算耗尽时保留进度，再按需要继续。

每5篇为一个显示批次，程序逐篇、逐组执行，不同时启动5个模型请求。
每篇每轮最多1–6组，每轮最多1–50篇、1–120个请求名额。每组正文最多9000字符，输出最多2048词元（模型计量文本长度的单位），另有提示和来源信息。
名额按每次片段处理保守扣减，缓存命中也占一个名额；实际模型请求和已获得词元用量另行记录，不能替代账单。
不自动重试。达到任一预算就暂停，不会为了找到阳性结果自行扩大调用；找到阳性也不会把剩余候选偷偷跳过。

手动模式最多5篇，每篇独立检索，整次最多24组，页面会根据所选篇数限制每篇额度。
有文字但未命中、没有可读文字与调用失败分别展示，不能把选中某篇当作已经完成抽取。

## 摘要与正文

有本地可读全文或已获取开放正文时，优先从正文选择候选并保留同篇相邻上下文。正文额度不是整篇全文阅读。
没有正文时可处理摘要；摘要未提到基因时也不直接硬排除该摘要，模型输出仍需通过目标、组别和原句核查。
摘要没有给出适用比较时保留“摘要不足，待查正文”，不自动解释为论文无证据。
当前正文片段没有适用候选时保留“当前片段未检出，待补查”，可在新一轮额度内寻找其他命中。
补查跳过已成功组的锚定片段及其已包含的相邻片段；新组的上下文仍可能有重叠。没有更多命中时转为人工核对，不循环重发同一成功组。

可以明确勾选“缺少正文时，尝试获取可用开放正文”。这需要在线文献开关，使用已有的按编号核对的Europe PMC服务，不调用模型、不绕过付费墙。
这一步在论文进入模型前尝试获取正文，最多涉及本轮开始处理的论文；获取失败会保留状态与说明。
没有开放正文不代表没有全文；当前未解析图片、结构化表格、补充材料或扫描图片文字。

## 暂停与继续

“暂停扫描并保存进度”会等待当前调用结束，不能撤回已发送文字或费用。
达到预算后，展开“继续未完成扫描或重试未解决项”，设置新一轮篇数及请求上限，重新确认外发与可能的新费用，再继续。
默认只处理未完成的候选组；已成功组不重发。所有轮次的证据、原句及人工修改保留在同一个任务中。

要补查摘要不足、当前片段未检出，或重试失败、中断项，需要额外勾选对应选项。
摘要模式可在继续时明确升级为“使用本地或已获取的正文”，也可选择尝试获取开放正文。改变范围、预算或材料版本后需重新确认。
已成功组不自动重新解释；新片段可形成补充证据。已经处理出阳性结果的论文暂不提供自动遍历剩余全文的功能。

服务重启后，使用研究空间恢复码找回任务。运行中的任务会标为已中断，不自动调用模型。
若某次请求中途断开，其结果或计费情况可能不确定。必须明确选择重试才会重新处理；旧的不确定记录仍保留。
更换模型设置或提取规则后不能继续旧扫描，应另建新任务，避免把不同设置混作同一次实验。
尚未准备的候选若文字或来源已改变，会标为来源变更并停止发送，需重新检索；明确补查时可以使用当前同一论文的新材料。

## 覆盖表怎么看

| 状态 | 含义 |
|---|---|
| 未处理／已部分处理，待继续 | 还有候选组未处理，不能作阴性结论 |
| 已处理候选文字 | 本轮所选文字处理成功，仍需核对原句与医学含义 |
| 摘要不足，待查正文 | 摘要没有通过检查的适用比较，正文尚不能排除 |
| 当前片段未检出，待补查 | 当前正文候选没有适用结果，可继续其他命中或人工检查 |
| 无新增命中，待人工核对 | 当前检索范围没有新的组可发送，不等于全文没有证据 |
| 暂无可读文字／正文未命中 | 本次不能按现有文字判断 |
| 处理失败／调用中断 | 没有完成可靠处理，不作为无证据 |
| 来源已变更 | 未自动发送变更后的材料，需核对后新建扫描 |

“仅摘要”“正文候选片段”“正文片段与摘要”说明实际成功处理的文字范围。
失败和中断的输入另有记录；不能把成功片段数、累计字符数或候选数量当作独立论文数、全文覆盖率或医学准确率。
可下载逐篇覆盖与调用记录，包含材料版本、候选内容摘要、尝试状态、每轮预算及已获得用量。
原句存在与模型理解正确是两件事；结果仍需人工复核，不按多数票生成统一基因—疾病方向。

## 保存与已知边界

检查点、候选文字和该扫描的模型缓存保存在私有运行目录`scans/`，持续保存，独立于24小时临时任务目录。
删除对应任务时检查点一起删除；删除收藏与删除扫描任务分别处理。继续尚未准备的论文需要其收藏和原本地索引仍可用。
停机后应备份整个私有运行目录及配置；这些材料和恢复码不进入公开代码仓库。

本版借鉴PaperQA2（论文问答）的多次取证及ASReview（辅助文献筛查）的逐篇管理思路，没有接入这两个项目的完整程序。
尚未接入PubTator（生物医学实体关系平台）的名称统一或主动学习排序，也不让模型自行无限追加网络查询。
论文发现仍受每源最多100篇、关键词和别名覆盖限制；批量扫描覆盖的是当前候选清单，不是全部网络或整个本地库的全量抽取。
真实模型质量、漏检率及方向准确率仍需独立人工参考与匹配范围的评测。
